# 🧶 Site de Crochê

Site vitrine desenvolvido para divulgação de produtos artesanais em crochê.

O projeto apresenta diferentes categorias de produtos, como:

- 👗 Roupas
- 🏠 Tapeçaria e decoração
- 🍽️ Conjuntos para mesa
- 🧸 Amigurumis

### ✨ Funcionalidades

- Catálogo de produtos
- Organização por categorias
- Design responsivo
- Botões de contato via WhatsApp
- Área para encomendas personalizadas

### 💻 Tecnologias

- HTML
- CSS
- JavaScript
